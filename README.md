# claude-plugins

A Claude Code plugin marketplace. It hosts plugins that install into
Claude Code (`~/.claude/`).

## Install a plugin from this marketplace

```text
/plugin marketplace add jimbarritt/claude-plugins
/plugin install <plugin-name>@jimbarritt-claude-plugins
```

## Available plugins

| Plugin | Description |
|---|---|
| [`software-english-lint`](software-english-lint/README.md) | Lints Claude Code output against [Software English](https://github.com/jimbarritt/software-english). |
